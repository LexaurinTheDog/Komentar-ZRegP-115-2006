# Komentář k zákonu č. 115/2006 Sb., o registrovaném partnerství a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o registrovaném partnerství — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; pojem partnerství, neexistence a neplatnost, práva a povinnosti partnerů, vyživovací povinnost, zánik a zrušení partnerství soudem a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-2006-00115_2025-01-01`.
